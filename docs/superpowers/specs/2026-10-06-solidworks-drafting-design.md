# 独立 SOLIDWORKS 制造图 skill 设计

2026-10-07 发布位置更新：本技能已拆分至独立 `solidworks-drafting-skill` 仓库，仓库根目录即安装包。下文 `skills/solidworks-drafting/` 是初始整合时期的路径记录；当前相应资源在根目录。自动 DimXpert 方案和局部视图按用户决定延期。

日期：2026-10-06。此文替代早期“旧技能作为入口、交付 PNG”的设计。新包拟名 `solidworks-drafting`；下述新增能力是实现目标，尚未作为已完成能力发布。

2026-10-06 后续用户修正优先于早期规划：保留已认可的原模板图框、分区、标题栏、字体与箭头，只优化内部视图比例/位置、标注及表格。网站仅作排版参考；改变纸幅时必须选用对应的认可模板，不重画或缩放原图框。每轮及时关闭本轮生成/打开的文档、释放 COM 引用、检查内存，保留用户已有未保存文档。当前真实运行状态与不支持项以新包 `references/verification.md` 为准，不把设计目标等同于实现声明。

最新范围决定：自动 DimXpert 方案和局部视图先不实现，作为用户后续测试后再评估的待改进项，不作为当前阶段验收条件。已有模型尺寸与已有 PMI 的复用保留；不支持的必要定义仍报告缺项。下文提到这两类新增能力的地方均为延期候选方案。

## 一句话目标

把旧工程图技能和迁移技能的可用代码整合为独立新 skill，利用原生尺寸与 PMI、参考图模板和动态排版，从三维零件生成尺寸完整、可读的单页工程图，只交付 DWG 和 PDF。

## 已确认要求

| 项目 | 要求 |
| --- | --- |
| 输入 | 第一阶段一次一个已保存且无未保存修改的原生 SLDPRT；STEP/B-rep、批处理和装配以后扩展 |
| 新技能 | 同一包包含 SKILL.md、参考说明、配置、示例、PowerShell/C#/Python 代码和测试；安装后不依赖两套旧 skill |
| 主入口 | 新 `solidworks-drafting`；旧技能保留兼容与历史使用，新包不能只是路由到旧技能 |
| 使用 | 指定模型及可用模板配置后自动执行，问题集中报告；失败最多三次有依据修复 |
| 交付 | 交付目录只有一个 DWG 和一个 PDF；不生成 PNG 交付文件 |
| 内部文件 | 原生 SLDDRW、必要模型副本、计划、事实、日志和验证报告保存在 internal/，供复核与恢复 |
| 图幅 | 严格单页 A4/A3/A2，允许横纵向；A2 内无法同时满足完整性与可读性时报告失败 |
| 视图 | 根据特征需要选择正投影、反向、剖视或局部视图，不固定三视图；相关正投影视图比例一致 |
| 投影 | 跟随所选模板，并核对视图位置、对齐和投影标识一致 |
| 尺寸 | 覆盖所有可靠确定的必要几何定义；常规尺寸、表格和混合表达均允许 |
| 制造信息 | 复用已有尺寸/PMI及明确指定规则；不猜公差、功能基准、螺纹等级、粗糙度和材料 |
| 风格 | 从用户提供的网站筛选实际合适图纸总结排版，不限定所谓 45°方式；旧迁移图仅作额外参考 |
| 等级 | 工程师审核用制造图草稿；不能自动宣称生产放行 |

“只有 DWG/PDF”约束最终图纸交付，不取消内部验证文件。自动流程中仍采用 SOLIDWORKS 原生临时工程图完成投影、关联标注及保存重开，再导出 DWG；直接拼写 DWG 不作为第一阶段实现路线。

## 现有代码与合并边界

旧仓库：[solidworks-drawing-skill](https://github.com/lihan960222-sys/solidworks-drawing-skill)。保留其几何检查、边引用、计划校验、标准/直线完整剖视、支持的关联尺寸、通用表、尺寸分层、源件完整性及保存重开代码。

迁移来源：本地 `solidworks-automation-port/skill/solidworks-automation-port`。提取其串行会话锁、隐藏 STA 工作进程、超时未知状态处理、模型尺寸导入与视图/尺寸枚举；不把完整建模、装配和宏主机搬入新包，不要求运行时调用该技能。

新包放入旧仓库的 `skills/solidworks-drafting/`，独立可安装。旧根目录 skill 单独修正禁止表格文档，维持 v1 实际能力；新增自动化功能放在新包，不能通过改旧文档宣称新增代码已实现。同步到此仓库后以这里为新设计与计划的维护位置，早期 cad-agent 设计标记已被替代。

## 流程与状态

源件检查 → 特征/尺寸/PMI清单 → 工作副本与受控尺寸定义 → 模板、视图及比例候选 → 原生视图和标注 → 排版反馈 → 原生保存重开 → DWG 导出 → 独立回读 DWG → 从回读文件生成 PDF → 完整性与视觉检查 → DWG/PDF交付。

每次使用新运行目录，不覆盖既有结果。一个串行驱动操作 SOLIDWORKS，所有阶段使用同一会话锁。超时后记录 `UNKNOWN`，先观察文档和已写文件，不直接重跑；只可结束该次自建工作进程，不能结束 SOLIDWORKS。

源件只读。需要新增 DimXpert 信息时建立工作副本，单独检查副本几何，并重新获取其拓扑引用；原件的引用不能未经验证套用到副本。模型计算使用 SI，规划/图纸使用 mm，COM 边界明确转换。

运行状态：`FAILED`、`UNKNOWN`、`REVIEW_REQUIRED`、`DRAFT_VERIFIED`。`DRAFT_VERIFIED` 要求几何覆盖、源件完整性、原生保存重开和 DWG/PDF 内容及视觉检查全部通过；它仍是审核草稿。数值检查通过但视觉未检查时为 `REVIEW_REQUIRED`。

覆盖状态：`covered`、`missing_geometry_definition`、`unsupported_operation`、`missing_manufacturing_requirement`。已知必要几何缺失或操作不支持会阻止完整草稿通过；缺少用户未提供的制造规格进入集中待审核项。

## 三类能力的分工

模板规定图框、标题栏、字体、箭头、线型、默认间距及投影；DimXpert/已有模型尺寸提供有来源的尺寸和 PMI；规则规划器根据特征、投影尺寸和标注空间选择视图、纸幅、比例、位置以及尺寸层/表格。

`InsertModelAnnotations3` 最后参数是 `UsePlacementInSketch`，不是 DimXpert 开关。已有模型尺寸通过该入口导入；DimXpert 注解使用 `IView.ImportAnnotations` 的对应开关，核对实际类型与关联。迁移代码的尺寸遍历不能直接当作完整清单，需递归特征/子特征并按对象身份去重。

Auto Dimension Scheme 只有 PlusMinus/Geometric 两种公差类型，不能假定无公差自动模式；因此只有输入了明确且完整的制造规则才运行该方案，否则复用已有 PMI、补名义几何尺寸，并报告制造规格缺项。[官方枚举](https://help.solidworks.com/2025/english/api/swdimxpertapi/SolidWorks.Interop.swdimxpert~SolidWorks.Interop.swdimxpert.swDimXpertAutoDimSchemeToleranceType_e.html)

`AlignDimensions` 只针对选中尺寸执行局部自动排列，并在执行后重新读取位置；它不是全图碰撞求解器。[官方示例](https://help.solidworks.com/2025/english/api/sldworksapi/auto-arrange_dimensions_example_csharp.htm?format=P&value=)

## 参考模板与动态排版

参考库：[用户指定 DWG 图纸库](https://www.innerscene.com/tools/library/drawings/format/dwg)。按板类、轴类、支架类选少量包含实际尺寸和标题栏的机械图，必须打开检查内容后才归纳规则，不能只根据目录标签声称完成研究。

提取绘图区/标题栏禁入区、视图比例和对齐、尺寸分层、引线、文字、箭头、线宽和留白。只学习排版，不复制样图尺寸、公差及制造信息到用户模型。参考 DWG 私有保存，公开仓库只保存来源链接及通用归纳；DWG 不能直接当作 drwdot，采用合法本地模板副本及配置。

先按几何覆盖选择视图，再尝试 A4/A3/A2 横纵向及有限常用比例。以模型投影范围、文字层及表格空间计算初始位置，再读取原生视图和标注实际显示数据反馈修正。保留字号，不靠缩小文字、漏尺寸或额外页面解决拥挤。

无法通过通用 GetBox 覆盖全部注释边界。显示数据、文字度量及实际图纸渲染用于保守碰撞检查；未量测项目留为视觉检查，不宣称严格全图无碰撞。局部修复顺序：尺寸层/引线 → 表格 → 视图/表格位置 → 比例/纸幅。

## 尺寸与表格

每个特征记录几何证据、要求表达的信息、已有尺寸/PMI、选用视图、尺寸或表格行、单位及来源。去重依据实体、含义和方向，不能只看尺寸数字。

覆盖外形、台阶、槽、孔径/孔位/孔深/数量/通盲、圆角和倒角；线程/孔向导信息须有明确来源。必要剖视、局部视图必须实际创建并验证，否则报告不支持，不用平面贴图伪装成原生视图。

允许常规尺寸、特征表或混合表达，不设强制孔数门槛。每个表格行对应图中唯一编号；位置数据必须带单位、原点和轴向；表格不能替代理解形状所需的剖视与关键轮廓尺寸。通用表非关联性需明确记录并重查。

旧 v1 仅支持 `nominal_hole_schedule`；新 v2 额外支持 `nominal_feature_schedule`，必须由相同的几何定义数据生成，校验每行来源、适用字段、单位和标识。不能通过自由文本万能表绕过覆盖检查。

## DWG 到 PDF 的验证关口

先用自建零件验证 DWG 导出、独立回读及 PDF，这决定后续实现是否可用。显式快照并恢复 DXF/DWG 相关设置，固定单位、纸幅、活动页、比例与版本。保留工程图纸面布局，避免误开几何 1:1 输出改变图框关系。[官方导出选项](https://help.solidworks.com/2020/English/SolidWorks/sldworks/r_dxf_dwg_export_options.htm)

开发实测后采用已安装 eDrawings 直接回读交付 DWG 并打印 PDF：原 SOLIDWORKS 导入路线在本机改变尺寸值和位置，已经否决。新路线必须确认加载文件身份、单页、打印完成、纸幅及 DWG/PDF 哈希；文字轮廓化、字体映射与特殊符号仍需视觉核对。不得以内部原生 PDF 冒充 DWG 回读。原导入接口的验证失败记录保留。

PDF 必须来源于交付 DWG 的独立回读，不能以原生工程图 PDF 冒充这一步。字体、特殊符号、表格、剖面、尺寸和纸幅在真实输出中核对；回读后尺寸若变为普通图形，就按实际类型报告，不宣称仍关联三维模型。原生回读若不可用，记录证据并报告流程失败，再选择经验证的转换后端，不自动安装未验证软件。

## 验收与发布

合成样例至少包含板类密集孔群、轴类台阶/孔深、支架槽/圆角/倒角，以及 A2 内仍无法完成布局的失败例。每例比较关键几何定义、源件摘要、保存重开、投影、单页、字号、表格与真实 DWG/PDF。

开发验收追加代表性图纸的独立盲重建：新执行者只接收冻结审核 PDF和通用工具，重建结果冻结后才提供源件比对。隔离失败或未做测试则记录未通过；不是每次用户出图都重建。

安装并发布前核对技能文档、计划契约、可调用代码和报告能力一致；不能用文档更新代替实现。只同步通用说明、代码、配置和合成测试；不上传用户模型、参考 DWG、真实工程图和原始尺寸报告。旧 skill 表格文档修正与新包发布分别记录提交。
